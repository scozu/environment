# Codex (optional)

This directory is for the **Codex CLI** only. It is **not** symlinked to `~/.codex` by default (see `.stow-local-ignore` in the repo root).

If you use Codex, link it yourself, for example:

```bash
ln -s ~/Developer/environment/.codex ~/.codex
```

For **Cursor** in this repository, use `./.cursor/rules/` instead of duplicating policy here.
